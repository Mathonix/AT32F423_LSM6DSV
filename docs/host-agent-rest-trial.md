# 上位机交接：静止检测试运行参数

这次只改了固件内部的 VQF 静止参数。协议、帧格式、档位编号、遥测字段都没有变。网页先不要改，也不要部署。已经能识别第 4 档、capabilities 为 4 的上位机可以继续用。

板上已经是这版程序。不要再刷，不要改保存的档位。

## 现在的参数

四档使用同一组静止门限。加速度时间常数、输出平滑、外层保持时间仍按档区分。

| 参数 | 板上现在的值 | 作用 |
| --- | --- | --- |
| restThGyr | 0.6 °/s | 陀螺静止门限，四档相同 |
| restThAcc | 0.15 m/s² | 加速度静止门限，四档相同 |
| restMinT | 1.0 s | 连续满足门限后才置静止 |
| biasSigmaRest | 0.035 °/s | 静止零偏更新的信任程度 |

没动的部分：restFilterTau 0.5 s，biasForgettingTime 100 s，biasClip ±2 °/s。本文当时运动零偏是关的；后续已单独打开，见 `docs/host-agent-motion-bias.md`。零角速保持的锁定门限仍是进入 0.30 °/s、退出 0.70 °/s，不看 restMinT。

各档仍不同的部分：

| 档 | 加速度时间常数 | 外层保持 | 输出时间常数 |
| --- | --- | --- | --- |
| 0 响应优先 | 1.0 s | 1.5 s | 2.0 / 0.15 / 0.04 s |
| 1 均衡 | 2.5 s | 0.8 s | 4.0 / 0.50 / 0.10 s |
| 2 静态稳定 | 4.0 s | 0.4 s | 6.0 / 1.50 / 0.20 s |
| 3 零角速保持 | 2.5 s | 0.8 s | 4.0 / 0.50 / 0.10 s |

第 3 档在六轴下仍按角速度锁定发布航向。停稳后大约 100~200 ms 锁定，明显转动后大约 3 ms 解除。restMinT 从 1.5 s 改成 1.0 s 不会改变这个锁定时间。九轴选第 3 档不锁磁力计航向。

## 用户能感觉到的变化

静止零偏更挑环境：陀螺合成角速度要低于 0.6 °/s，加速度模长偏差要低于 0.15 m/s²，并连续保持 1.0 s，才会开始按 0.035 °/s 的噪声更新零偏。

相对刚换掉的那版，均衡、静态稳定、零角速保持的静止门限收紧了（原先分别是 1.0/0.25、1.5/0.40、1.0/0.25）。响应优先的静止门限本来就是 0.6 °/s 和 0.15 m/s²。静止确认从 1.5 s 缩短到 1.0 s。静止零偏噪声从 0.03 °/s 放到 0.035 °/s。

## 上位机不用改的部分

- 档位仍是 0 响应优先、1 均衡、2 静态稳定、3 零角速保持。
- `0x26` / `0x0B` 和 `0x27` 的字节布局不变。capabilities 仍是 4。旧固件的 3 仍要能解码。
- 滤波帧里的两个 float 仍是当前档的输出平滑时间，不是 restMinT，也不是 biasSigmaRest。第 3 档回读仍是 4.0 / 0.50 s。
- 这四项静止参数不在协议里，界面读不回来。
- 没有新的诊断字段。

界面现有提示已经和固件不一致，先保持原样，等用户要求再改文案：

- 均衡仍写着静止门限 1.0 °/s、0.25 m/s²。
- 静态稳定仍写着静止门限 1.5 °/s、0.40 m/s²。
- 零角速保持仍写着滤波参数与均衡相同。输出平滑确实仍与均衡相同，静止门限也已经相同，但不要据此再改协议。
