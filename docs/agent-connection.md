# Agent 接入说明：UART、USB、CAN 与配置

给后续 agent 用。控制通道只有 UART 和 USB CDC，两边都是同一套 AA55。CAN 是独立的经典 CAN 数据口，参数也从 UART 或 USB 下发。浏览器不能直接打开 CAN 适配器。

先查询再改。本说明里的 COM 号是这台电脑上一次核对的结果，拔插后会变。用 VID、PID、序列号认设备。

## 先认接口

| 接口 | 这台电脑上一次看到的口 | 认设备 | 复位后 |
| --- | --- | --- | --- |
| 板载 USB CDC | COM16 | VID `0x2E3C`，PID `0xF401`，序列号 `22EC987C8068` | 端口会掉线并重新枚举。Windows 的 COM 号可能仍是 COM16，Web Serial 里的旧对象不能接着用 |
| 外接 UART | COM6 | WCH VID `0x1A86`，PID `0x8012`，序列号 `349B8F06B96E` | 转接器不掉线，Bootloader 和应用都还在这个口上 |
| CAN | 没有 COM 口 | MCU 引脚经外部收发器上总线 | 改 CAN 参数不重启。改波特率时保留 USB 或 UART，避免只剩 CAN 一条路 |

不要选 VID 为空的蓝牙串口（这台机器上出现过 COM9、COM10、COM11、COM12、COM42、COM43、COM52、COM53）。Web Serial 的 `getInfo()` 没有序列号，网页里只靠 VID/PID：`2E3C:F401` 走 USB 升级路径，其余已打开的口（含 WCH 和测试桩 `2E3C:5740`）走 UART 路径。

两路串口都是 2 000 000 波特、8 数据位、无校验、1 停止位。打开时不要故意拉 DTR/RTS 去复位；比较滤波时多余的打开可能赶上陀螺初始化，读到的零偏不能当作稳态。

当前维护的网页在 `upper/gyro-live`。`tools/web_host` 是旧页面，没有滤波三档。本地预览：

```powershell
Set-Location 'E:\Desktop\1_Program\AT32F423_LSM6DSV_SPI_Test\upper\gyro-live'
npm run dev
```

浏览器打开 `http://127.0.0.1:8798`，用 Chrome 或 Edge。点连接后由人选择串口，agent 无法代替这次授权。脚本侧用 `tools/usb_host/protocol.py` 的 `pack_command` / `unpack_binary`，不要另写 CRC。

## 线

MCU 是 AT32F423KCU7-4。

| 信号 | 引脚 | 外设 |
| --- | --- | --- |
| UART TX | PA0 | USART4 TX，复用 8 |
| UART RX | PA1 | USART4 RX，复用 8 |
| CAN RX | PA2 | CAN2 RX，复用 9。这是控制器数字脚，不是 CANH |
| CAN TX | PA3 | CAN2 TX，复用 9。这是控制器数字脚，不是 CANL |
| USB D+ | PA12 | OTGFS1 |
| USB D− | PA11 | OTGFS1 |

UART 交叉连接：板子 TX 接适配器 RX，板子 RX 接适配器 TX，共地。CAN 必须经过收发器再接到 CANH/CANL，总线两端要有终端电阻。把 PA2/PA3 直接接到 CANH/CANL 不会通信。回环不能代替实线。USB 使用芯片内部 HICK 加 ACC 做 48 MHz，工程定义了 `USB_VBUS_IGNORE`。VID/PID 在 `middleware/usbd_class/cdc/cdc_desc.h`。

应用和 Bootloader 的 USB 身份相同。进入 Bootloader 后 CDC 会断开再出现；UART 转接器保持打开。

## 共用的 AA55

UART 与 USB 的命令、应答、遥测格式相同。帧为：

```text
AA 55  MSG_ID  LEN  SEQ  PAYLOAD  CRC16_L  CRC16_H
```

CRC16-CCITT-FALSE：初值 `0xFFFF`，多项式 `0x1021`，覆盖 `MSG_ID` 到 `PAYLOAD`，低字节在前。`LEN` 最大 64。Python 里 `pack_command(cmd_id, seq, payload)` 已经按这个组帧。

ACK 是 `0x90`，负载 4 字节：`cmd`、`status`、`detail`（u16 小端）。`status`：0 成功，1 未知命令，2 参数非法，3 执行失败。

1000 Hz 遥测会灌满缓冲。查询前先读空输入，再对上应答序号。单次诊断在满速输出时可能超时，清缓冲后重试。

空负载就能读、不必进设置模式的命令：

| 命令 | ID | 应答 |
| --- | --- | --- |
| PING | `0x10` | ACK，成功时 detail 为 0 |
| 系统信息 | `0x14` | `0x05` |
| 设备配置 | `0x1F` | `0x07`，当前固件是版本 3、28 字节 |
| CAN 配置 | `0x21` | `0x08`，24 字节 |
| 滤波配置 | `0x26` | `0x0B`，16 字节 |
| 融合诊断 | `0x28` | `0x0C`，60 字节 |
| 六面校准状态 | `0x24` | `0x0A` |

`0x07` 版本 3 的负载：字节 2 是当前融合模式，字节 3 是已保存模式；输出频率 u16 在偏移 8；其后先 UART、后 USB，各 4 字节 `format, legacy_mode, mask`；初始化毫秒在偏移 18；当前量程、已保存量程、已保存输出频率三个 u16 在偏移 22、24、26。量程单位 dps。

文本 `vofa`（十六进制 `76 6F 66 61`，可带 CR/LF）会把 UART 和 USB 当前输出都改成 JustFloat，不写 Flash，不进设置模式。二进制负载里的同样字节不会触发。

## UART

1. 用 VID/PID/序列号找到 WCH 口，按 2 000 000 8N1 打开。
2. 清输入缓冲，发 PING，等到 `0x90` 且 status 为 0。
3. 发 `0x1F`、`0x21`、`0x26`，记下当前模式、量程、频率、两路输出和 CAN。
4. 需要改保存项时再进设置模式。改完读回，再 `0x18` 退出。

这个口在 MCU 复位后仍在。Bootloader 的 HELLO 在这里返回应用基址 `0x08008000`。网页升级时，只要当前打开的不是 `2E3C:F401`，就只重开这同一个 SerialPort，不调用 `getPorts()`。

## USB

1. 用 `2E3C:F401` 找到板载 CDC，同样 2 000 000 8N1。CDC 忽略波特率数值，网页和脚本仍按 2 000 000 打开，和 UART 保持一致。
2. PING 和查询与 UART 相同。`0x07` 的 source 字段表示这条应答来自哪一路，不要假设两路输出配置一样。
3. 发 `0x16` 或保存启动项并立即重启后，先关掉旧句柄，再按 VID/PID/序列号等新的 CDC，最长约 15 秒。HELLO 必须是 `0x08008000`。

网页 USB 升级只接受新出现的一个 `2E3C:F401`。升级前已经授权的另一块同型号板不能拿来顶替。同时出现两块新的同型号口时，在擦除前停止。进度 95% 表示整包已经校验，正在等应用 PING；不要断电，不要再点一次升级。100% 只在 PING 成功之后。公共站点 `gyro3.233688.xyz` 在这份本地页面发布之前仍是旧的重连逻辑。

只给升级页应用 `.bin`。当前镜像是 `build/lsm6dsv_spi_test/release-9axis/lsm6dsv_spi_test.bin`，80204 字节，从 `0x08008000` 写 208 KiB 应用区。同名 `.hex` 只用于 SWD。HEX、Bootloader 镜像和从 `0x08000000` 开始的整片镜像都会被页面拒绝；若用别的工具写进去，会擦掉 Bootloader 或校准区。

## CAN

CAN 不走 AA55，也不走 JustFloat。浏览器和 `tools/usb_host` 都不打开 CAN 适配器。PCAN 等适配器只用于看总线；改参数仍走已经连上的 UART 或 USB。

出厂默认：CAN_ID `0x001`，MST_ID `0x6FF`，1 Mbit/s，主动输出，只发欧拉角，每类间隔 1 ms。主动帧发到 CAN_ID。8 字节寄存器请求也发到 CAN_ID，应答在 MST_ID。标准帧 8 字节，不使用扩展帧和 RTR。

波特率序号 0 到 7：1M、500k、400k、250k、200k、100k、50k、25k。400k 实际约 401069 bit/s。PCLK1 为 75 MHz。

主动输出掩码：bit0 加速度/温度，bit1 角速度，bit2 欧拉角，bit3 四元数。欧拉角顺序是 Pitch、Yaw、Roll。加速度 m/s²，角速度 rad/s，角度度。掩码 0 只关主动发送，请求仍可应答。四类都选且间隔 1 ms 时，每类 1 kHz，合计约 4 k 帧/秒。固件拒绝超过标称带宽 80% 的组合；25 kbit/s 且四类全开时，间隔至少 27 ms。

从串口写入用 `0x22`，必须已在设置模式。负载 11 字节：

| 偏移 | 内容 |
| --- | --- |
| 0 | CAN_ID，u16 小端，0..0x7FF |
| 2 | MST_ID，u16 小端，0..0x7FF |
| 4 | 每类间隔，u16 小端，1..10000 ms |
| 6 | 波特率序号 0..7 |
| 7 | 0 请求/应答，1 主动输出 |
| 8 | 掩码 0..15 |
| 9 | 必须为 0 |
| 10 | 0 仅当前运行，1 写入 Flash |

成功时先 ACK，再来 24 字节的 `0x08`：版本、初始化成功、当前 10 字节、已保存 10 字节、bus-off、保留。bus-off 只说明控制器状态，不能证明线接对了。保存失败会滚回运行配置。改 CAN 不重启整机。

经 CAN 自己改波特率时，先在旧速率发出应答，确认发出后才切换；100 ms 内没有确认就取消。改完从 USB 或 UART 读 `0x21`。经 USB/UART 改波特率则立即生效。

旧命令 `0x1A` 只改 11 位节点 ID，也要设置模式，不会动待重启的启动项。网页里的完整面板是「CAN 输出」，用 `0x22`。旁边单独的「CAN 节点」才是 `0x1A`。

## 配置怎么下

凡是会写入启动项、滤波、CAN 或开始六面校准的命令，顺序固定为：`0x17` 进入设置，发命令，读回应答，需要时再查询，最后 `0x18` 退出。`0x18` 会取消正在进行的六面校准。退出设置也会取消校准，所以校准过程中不要退出。

| 要改的项 | 命令 | 是否要设置模式 | 何时生效 |
| --- | --- | --- | --- |
| 融合模式、快速启动、初始化时长、陀螺量程 | `0x1E` | 要 | 保存后重启才进融合和量程。`apply_now=1` 会立刻重启，只发一次 |
| 输出频率 | `0x1D`，u16 小端 Hz | 不要 | 先写 Flash，成功后立即改运行频率 |
| 某一路输出格式和字段 | `0x20` | 不要 | 立即作用于指定口。持久化位为 1 时同时写 Flash |
| 两路一起改回旧预设 | `0x13` | 不要 | 只改当前运行，UART 和 USB 一起变 |
| 滤波档位 | `0x27` | 要 | 立即改变输出平滑。持久化为 1 时重启仍保留。0..3 合法，4 拒绝 |
| CAN | `0x22` | 要 | 立即改变 CAN，不重启 MCU |
| Yaw 置零 | `0x11` | 不要 | 立即 |
| 六面加速度校准 | `0x1C` 开始，`0x25` 取消 | 开始时要 | 六面完成后自动保存。退出设置会取消 |

`0x1E` 负载可以是 3、5 或 7 字节：`mode, fast_start, apply_now`，可选 `init_ms` u16，再可选 `range_dps` u16。模式 0 六轴、1 九轴、2 九轴相对角。快速启动和立即重启只能是 0 或 1。初始化时长 100..60000 ms。量程只允许 125、250、500、1000、2000、4000。短格式不改已保存的时长或量程。`apply_now=1` 在 ACK 成功后复位应用，不要紧接着再发一串配置。

频率必须整除 2000：1、2、4、5、8、10、16、20、25、40、50、80、100、125、200、250、400、500、1000、2000。它只管 UART/USB 遥测。CAN 的毫秒间隔单独计算，1000/period_ms 才是每类帧率。

`0x20` 负载 5 字节：`port`（0 UART，1 USB）、`format`（0 JustFloat，1 自定义 AA55）、`mask` u16、`persist`。mask 的 bit0..bit8 是 Yaw、Pitch、Roll、Ax、Ay、Az、Gx、Gy、Gz。单位是度、m/s²、度/秒。只发送选中的 float，顺序不变。mask 0 关闭遥测，命令应答仍在。format 不能写成 2；2 只出现在读回里，表示当前还是旧预设。

滤波 `0x27` 两字节：`profile` 0..3，`persist` 0 或 1。0 响应优先（2.0 / 0.15 / 0.04 s），1 均衡（4.0 / 0.50 / 0.10 s），2 静态稳定（6.0 / 1.50 / 0.20 s），3 零角速保持（ZARU / Stationary Heading Hold）。三个数是磁力计、静止输出、运动输出的时间常数。零角速保持与均衡用同一组时间常数；只在六轴下，按扣除陀螺零偏后的三轴角速度锁定对外航向，不再等待 VQF 的 1.5 s 静止标志。进入约 0.30 °/s RMS 持续 50 ms，退出约 0.70 °/s 持续 3 ms。检测到运动后连续恢复。九轴选这一档仍用均衡参数，但不锁磁力计航向。`0x0B` 的 capabilities 现在是 4；旧固件回 3 也要接受。这些档不改量程、带宽和零偏估计。代码默认是均衡；具体板子以 `0x26` 读回为准。2026-10-02 已烧录带零角速保持的 9 轴镜像，并经 USB 把滤波运行值和保存值都写成 3。当时读回是六轴、量程 ±125、capabilities 4、时间常数 4.0 / 0.50 s。下一次任务先读 `0x26`，不要把这次读回当成出厂默认，也不要擅自改回别的档。

指示灯：六轴是绿色呼吸，九轴且磁力计就绪是青色，启动陀螺标定是蓝色闪烁。设置模式下六轴/九轴是对应的常亮颜色。灯的颜色不能代替 `0x07` 读回。

这些命令现在固定失败，不要把它们写成已完成：`0x12` 陀螺重标定，`0x1B` 运行时 60 秒陀螺标定（detail `0x0601`）。六面校准在设置模式外或负载非空时 detail 为 `0x0602`；已经在校准则为 `0x0604`。

## 建议的连接顺序

1. 认口。控制用 USB CDC 或 WCH UART 里已经通的那一个。两条都通时，改配置用哪条都可以；升级时认清当前口是 USB 还是 UART。
2. 2 000 000 8N1，清缓冲，PING。
3. 读 `0x1F`、`0x21`、`0x26`。有未保存的页面草稿时，网页会拒绝升级和部分应用。
4. `0x17`，只改这次要改的项，读回 ACK 和对应查询，再 `0x18`。
5. 若 `0x1E` 带了立即重启，或发了 `0x16`，按上面的口分别重连。UART 等原口，USB 等新 CDC。重连后重新 PING，不要假设设置模式还开着。
6. CAN 线接好后，用适配器看 CAN_ID 上的主动帧，或向 CAN_ID 发 8 字节请求并在 MST_ID 等应答。同时用串口 `0x21` 核对。只看到 bus-off 时先查收发器、终端和波特率，不要反复写 Flash。

不要为了探活去发 `0x15` 系统复位或 `0x16` 进 Bootloader。板子已经停在 Bootloader 时不要断电；用原 UART，或勾选网页「设备已在升级模式」后选择新的 USB 口，重新上传同一份应用 bin。
