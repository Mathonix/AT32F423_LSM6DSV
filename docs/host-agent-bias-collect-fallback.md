## 设备行为

快速启动仍然默认关闭。正常开机仍先做静止采集。采集成功时和以前一样：用这 2 秒的实测零偏，不确定度 0.035 °/s，并把结果连同温度写入历史。

采集失败时不再停在编译默认的 0, 0, 0 °/s。设备改用快速启动会选的那一个零偏：

- 当前温度 ±5 °C 内有历史时，取这些记录的平均，不确定度 0.25 °/s。
- 没有温度匹配的历史时，仍用 0, 0, 0 °/s，不确定度 0.50 °/s，指示灯按“没有历史”闪红。

这次回退值不会再写入历史，也不会打开快速启动那条后续的静止保存。采集成功的路径不走这个回退。
