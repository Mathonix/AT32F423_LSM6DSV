# CAN 配置（20260930b）

Web Serial 通过 UART / USB 的 AA55 控制通道修改本板 CAN2，不需要浏览器直接打开 CAN 适配器。此配置独立于 UART / USB 的 JustFloat、自定义协议和逐轴掩码。

## 使用

连接设备 → 进入设置模式 → CAN 输出面板 → 填写 CAN_ID、MST_ID、波特率、模式和间隔，勾选四类报文 → 应用。勾选“保存到设备”后断电保留；不勾选仅改变当前运行。页面同时显示当前/已保存配置。

CAN 采用达妙固定 8 字节标准数据帧，不使用 JustFloat，不拆分单轴。主动输出掩码按组控制：bit0 加速度/温度、bit1 角速度、bit2 欧拉角、bit3 四元数。掩码 0 关闭主动数据；不阻止请求/应答。

保留项目原有 ID 约定：主动发送在 **CAN_ID**；8 字节寄存器请求也发到 CAN_ID；应答在 **MST_ID**。参考 PDF 明确给出寄存器请求/应答 ID，但没有单独定义主动发送 ID，因此主动发送没有改变原有行为。附录的 4 字节快捷请求发到 MST_ID，负载为 `node_id:u16 LE, type:u8, CC`；必须明确匹配本节点，不接受广播重启。

## AA55 控制扩展

旧设备配置消息 `0x07` 保持版本 1、18 字节；capabilities bit3 表示支持本 CAN 配置扩展。新增 `0x21` 空负载查询，不需要设置模式。

`0x22` 设置负载 11 字节，要求设置模式：

| 偏移 | 字段 | 类型/约束 |
| --- | --- | --- |
| 0 | CAN_ID | u16 LE，0..0x7FF |
| 2 | MST_ID | u16 LE，0..0x7FF |
| 4 | 每类报文间隔 | u16 LE，1..10000 ms |
| 6 | 波特率序号 | u8，0..7 |
| 7 | 主动模式 | u8，0 请求/应答，1 主动输出 |
| 8 | 输出掩码 | u8，0..15 |
| 9 | 保留 | 必须 0 |
| 10 | 持久化 | u8，0 临时，1 保存 |

波特率顺序：1M、500k、400k、250k、200k、100k、50k、25k bit/s。PCLK1=75MHz：400k 使用分频 11、17 TQ，实际 401069.5 bit/s（+0.267%），需验证对端兼容；其他档位分频 5/10/20/25/50/100/200、15 TQ，精确对应标称值。

每类报文在所填间隔内各发送一次（全选四类、1 ms，即每类 1 kHz，总计 4 k帧/s）。调度限定一次最多三个邮箱，延迟时跳过过期积压，不阻塞采样环。校验按最坏 135 bit/帧，最多占用标称带宽的 80%。例如 25k、四类全选，间隔至少 27 ms；网页和固件都拒绝超载。

设置返回 `0x90` ACK 后返回 `0x08` CAN 配置消息。`0x08` 严格为 24 字节：版本 1、初始化成功标志各 1 字节；当前配置 10 字节；已保存配置 10 字节；bus-off、保留各 1 字节。10 字节配置与设置前 10 字节完全一致。bus-off 表示 CAN 控制器状态，不能仅凭它证明物理接线正常。

修改 CAN 不重启设备。保存失败回滚运行配置；Flash 写入、波特率切换后重新建立采样时间基线。V4 双槽 CRC 设置记录兼容 V2/V3：保留原模式、快速启动、CAN_ID、UART/USB 输出；CAN 新字段填默认值（1M、主动、欧拉角、1 ms、MST_ID 0x6FF）。旧 CAN ID 命令仍支持 11 位，不会覆盖待重启启动设置。

## CAN 数据与寄存器

参照 DM-IMU-L1 V1.2 的 CAN 数据布局和映射范围：加速度 m/s²，角速度 rad/s，欧拉角 °；欧拉角顺序 Pitch/Yaw/Roll；三轴为 16 位小端映射；四元数按 W/X/Y/Z 共 56 位打包，分量各 14 位。映射越界饱和，非有限数按 0 处理。四元数按位布局实现，不沿用附录解码示例里掩掉 W 低位的笔误。

8 字节寄存器请求：`CC RID R/W DD value:u32 LE`，返回 `CC RID DD status value:u32 LE`；读取四类传感器时直接返回对应的 8 字节传感器帧。拒绝 RTR、扩展帧、无关 ID、无效 R/W 和写只读数据寄存器。

| RID | 本项目支持行为 |
| --- | --- |
| 00 / 05 | 写：重启 / Yaw 置零 |
| 01..04 | 读：四类传感器数据；写拒绝 |
| 09 | 读固定 2（CAN）；写仅接受 2，不停掉 UART/USB |
| 0A | 读写间隔，单位 ms |
| 0B | 读写主动模式 0/1 |
| 0C | 读写波特率序号 0..7 |
| 0D / 0E | 读写 CAN_ID / MST_ID，完整 11 位 |
| 0F | 读写四类掩码；**本项目扩展，PDF 注明原厂固件不支持修改** |
| FE | 写：保存当前 CAN 配置，实际保存失败返回失败 |
| 06/07/08/FF | 校准/恢复出厂未开放，写返回失败，不伪报成功 |

参考 PDF 没有定义上述配置寄存器的完整数据宽度、间隔单位、输出掩码位义。这些明确是本项目约定，不保证直接控制原厂 DM-IMU-L1 的配置寄存器。串口快捷 AA 指令也没有扩展成全套达妙配置指令；网页用本项目 AA55 控制接口。

经 CAN 更换波特率：先在旧速率发 ACK，仅在确认发送成功后切换，100 ms 内无确认则取消；应随后从 USB/UART 查询实际配置。经 USB/UART 更换波特率则立即生效，不依赖 CAN 总线 ACK。保持独立控制通道，避免更换速率后失联。

## 测试

本机原生 C 测试覆盖映射边界、四元数位布局、路由、权限、全部速率/掩码有效性、负载上限、四类每类 1 kHz 调度、波特率 ACK 成功/超时、保存失败，以及 V2/V3 迁移与断电写失败。

网页单元测试 44 项；浏览器旧回归 14 步、输出配置回归 11 步；CAN 模拟浏览器验证 8 波特率 × 2 模式、保存/回读、独立性、参数拦截和保存失败。

`tools/serial/test_can_hardware.py --run-hardware` 为显式实板测试，UART/USB 共 512 组配置、11 组无效配置、保存/重启/恢复。`test/can.browser.check.mjs` 默认模拟串口；设置 REAL=1 时使用显式本地 COM16 字节桥，验证真实板子的网页控制，仍不覆盖原生 Web Serial 权限窗口和真实 CAN 总线。
