# AT32 Motion Studio Design System

The visual system is intentionally calm, dense and engineering-focused: low-contrast layered grays, 1 px borders, restrained 6–12 px radii, tabular telemetry numerals, Lucide icons and accent color reserved for connection/selection/attention states. Dark mode is not pure black and no large gradient/neo-industrial dashboard treatment is used.

Primary desktop target: 1920×1080 and 2560×1440 with Windows 125–200% scaling. The shell keeps the sidebar narrow and gives workspace plots/viewers priority.
