# 共享 BL 等待与上电零偏采集窗口

实板版本：`20261003e`。2026-10-04 已通过 MicroLink 配套烧录 BL 与 APP，并完成实板启动、回退和 USB 升级测试。线上上位机尚未部署本次变更。本轮没有温度补偿功能。

## 行为

设备持久化的 `gyro_init_ms` 是唯一启动窗口 T，范围 `0..60000` ms，默认 `2000` ms。BL 和 APP 使用同一份设备设置，Flash 格式仍为版本 8，不改变校准区地址。

- T > 0：BL 初始化 IMU 后开启 T 窗口，处理 UART / USB / WebUSB 升级协议的同时采集陀螺仪与加速度。到期且 APP 合法时跳转，不因运动、缺样或采集失败重新计时。
- 合格采集：APP 使用 BL 传入的零偏和平均重力，保存一条新历史记录。
- 不合格采集：APP 立即采用历史零偏。优先取当前温度 ±5 °C 内记录的均值；没有窗口内记录时取温度最接近的一条，同距离选较新的。无有效历史时使用编译默认零偏。回退结果不会作为一次新的启动采集写入历史；运行中的原有静止细化仍保留。
- T = 0：BL 检查 APP 向量合法后立即跳转，不启动 IMU 采集；APP 使用历史零偏。0 秒代表取消人为等待，仍有时钟、通信、传感器等正常初始化耗时。
- APP 无效：留在 BL 恢复入口。主动 `0x16` 进入升级：保持 BL 等待，不受 T=0 或到期影响。升级会取消本轮预先采集结果。

T 计时从 BL 的传感器初始化结束开始；APP 接收结果后没有第二段 T 采集。USB 断开、Flash 保存和 APP 硬件初始化是额外固定开销，因此“2 秒窗口”不是保证从电源沿到姿态输出精确 2.000 秒。

## 采集及交接

BL 复用 LSM6DSV 驱动、加速度校准及启动零偏校验。至少平均 1 kHz 的有效采样，角速度模长 ≤1 dps，重力模长偏差、100 ms 块内噪声及重力方向变化均须通过原有检查。窗口内任何拒绝、超过 5 ms 的采样间断、末段噪声超限或覆盖不足都回退。短窗口无法得到至少两个有效样本时也回退。

BL 的 DWT 计时扩展为 64 位，支持 150 MHz 下 60 秒窗口内两次 32 位计数回绕。

两份链接脚本均保留 SRAM 顶部 256 字节，初始 SP=`0x2000BF00`。64 字节交接区从 `0x2000BF00` 开始，含版本、T、量程、状态、采样数量、拒绝原因、温度、rad/s 零偏、m/s² 重力及 CRC32。APP 在初始化外设前消费一次，验证 CRC、版本、T 和量程；校验失败走历史。已有主动升级标志地址 `0x2000BFF0` 不变。

## 上位机协议

`0x1F` 查询，回复 `0x07`。配置版本升为 **4**，载荷仍为 28 字节，沿用 v3 布局：

| 偏移 | 字段 | 格式 |
| --- | --- | --- |
| 0 | 配置版本 | u8，4 |
| 4 / 5 | 当前 / 保存快速启动标志 | u8，由对应 T==0 派生 |
| 18 / 20 | 当前 / 保存 T | u16 LE，0..60000 ms |
| 22 / 24 | 当前 / 保存陀螺量程 | u16 LE，dps |
| 26 | 保存输出频率 | u16 LE，Hz |

保存仍为 `0x1E`，7 字节载荷：`mode fast restart T_lo T_hi range_lo range_hi`。fast 在新固件中由 T 派生；建议发送 `T==0 ? 1 : 0`。必须进入设置模式；保存 ACK 后回读确认，保存值在下次重启生效。

示例（模式 0、±1000 dps、保存但不立即重启，仅列载荷）：

| T | 载荷 HEX |
| --- | --- |
| 0 秒 | `00 01 00 00 00 E8 03` |
| 2 秒 | `00 00 00 D0 07 E8 03` |
| 60 秒 | `00 00 00 60 EA E8 03` |

新版本地上位机连接 v4 时隐藏快速启动复选框，始终显示 T 输入；连接 v1..3 时保留旧逻辑及最小 0.1 秒限制。v3 的量程、输出频率能力在 v4 继续有效。重启重连已有 90 秒期限，覆盖 60 秒窗口。

## 2026-10-04 实板结果

MicroLink `04CF952C7A94199D`，4 MHz SWD，AT32F423 ID `0x700A3253`。一次备份完整 256 KiB Flash，先写 APP、再写 BL；APP 完整分区与 BL 32 KiB 分区逐字节验证。烧录后还通过 USB CDC COM29 升级同一份 95636 字节 APP，BL 的 END CRC 校验及最终 SWD 全镜像校验通过，运行版本查询为 `20261003e`，型号 `AT32`。

| 情况 | 结果 | 采样 / 时序 |
| --- | --- | --- |
| T=0 | 直接采用历史，没有新增记录 | 0 样本，APP 就绪约 0.456 s |
| T=2 s，静止 | 使用新零偏，历史序号 +1 | 4001 样本，采集 2000 ms，APP 就绪约 2.535 s |
| T=60 s，静止 | 使用新零偏，历史序号 +1 | 120073 样本，采集 60000 ms，APP 就绪约 60.569 s |

| 60 s 采集期间 USB BL HELLO | 连续三次正常回复 | 采集仍通过，没有拒绝窗口 |

测试结束恢复六轴模式 0、T=2000 ms、±2000 dps、USB/UART 2000 Hz，输出通道、CAN、滤波及 ZARU 设置保持原值。旧格式 fast 标志规范为 0（T>0）；设置记录序号由测试写入递增。原 36 条历史均保留，成功启动新增 7 条，最终 43 条、sequence 136。运动及 T=0 回退不追加启动历史。最后一次板子放稳重启后采集 4000 样本，bias 为 `+0.283850163 / +0.034562483 / -0.373257190 °/s`；这仅是零偏估计数值，不代表校准误差。
