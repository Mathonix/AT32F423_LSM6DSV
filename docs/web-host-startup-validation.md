# 快速启动取消与初始化零偏时长修复

验收日期：2026-10-01（北京时间）。网页已发布至 https://gyro.233688.xyz/，资源版本 `20261001c`。

## 原因与行为

原网页每次收到启动配置读回都重新设置快速启动勾选，导致尚未保存的取消操作被覆盖；原固件正常启动分支也不再执行启动零偏采样。

新版在取消快速启动后显示“初始化零偏时长（秒）”，默认 2 秒，可填写 0.1～60 秒。刷新读回保留尚未保存的勾选、融合模式和时长；“撤销修改”恢复设备已保存值。保存成功须获得 ACK 和匹配的配置读回；失败或超时保留修改。保存后重启生效，可选择“应用后立即重启”。旧固件缺少时长能力时明确提示升级配套固件。

正常启动要求设备持续静止，按配置时长采集新零偏再启动姿态输出，移动或样本中断会重新计算静止采样窗口。传感器初始化时间不计入此窗口，因此从上电到输出的总时间会超过设定采样时间。等待超过设定时长加 10 秒仍未成功时，使用固定默认零偏并标记回退。快速启动保留温度匹配历史零偏复用行为。

配置记录升级至 V5，利用原 V4 的保留字存储毫秒时长，记录仍为 40 字节；旧记录默认迁移为 2000 ms，保留融合模式、快速启动、UART/USB 输出和 CAN 配置。协议配置回读 V2 为 22 字节，包含当前/已保存时长；旧 3 字节启动请求仍保留已存时长，新请求为 5 字节。
