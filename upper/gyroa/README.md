# gyroa 网页上位机

目标域名 `gyroa.233688.xyz`。保留可构建源码、真实 PCB 模型和 Worker，兼容设备配置 v1～v5；共享启动窗口需 `20261003e` 的配套 BL/APP。

`20261008rest1`：设置页新增“静置零偏估计”开关，需 APP20261008a 或更新的兼容固件。VQF/EKF 共用，立即保存并生效，无需重启，断电后保留。关闭后保持已有补偿、运动零偏估计及静置检测。重新开启需要重新满足静置确认时间。USB CDC、UART、WebUSB 使用相同命令：查询0x55、设置0x56(0/1)、回复0x57(version/active/saved/reserved)。只在成功ACK及同序号、匹配的运行/保存回读后显示保存成功；旧固件禁用开关并提示升级。发布目录为dist/public/；本轮未部署线上。

需要 Node.js ≥22.12.0，在本目录运行：

```sh
npm ci
npm run build
npm run dev
```

静态源码在 `src/public/`，Worker 在 `src/index.js`，构建复制到 `dist/public/` 并生成 SHA256 manifest。本地默认 `http://127.0.0.1:8833/`，已保留模型 bundle，无需 STEP 转换依赖。页面开发后重新构建即可。

登录目标 Cloudflare 账户后执行 `npm run deploy` 发布。本仓库只提供部署配置，不含账号凭证。

## 使用

`20261004c` 新增本次实际启动零偏查询 `0x37 → 0x38`（60 字节），校准页显示本次采用的来源、初值与当前总补偿。启动历史 `0x34` 的 wire version 2 使用 dps；旧 version 1 实际返回 rad/s，新页面自动换算。Flash 历史格式保持不变。旧固件不支持 `0x37` 时隐藏新面板。

桌面 Chrome/Edge 连接设备后，设置页可设启动窗口 0～60 秒（默认 2 秒）、融合模式与陀螺仪量程。T=0 使用历史启动；T>0 在 BL 升级等待期间采集，到期不合格立即使用历史。保存后可重启并自动重连原端口。旧固件仍显示原快速启动选项。

状态页显示真实板卡姿态；输出页配置 USB/UART/CAN；校准页提供六面加速度计校准、零偏历史及静置 VQF 初始化；设置页提供四档滤波和阈值。

升级页读取型号 AT32 和应用版本，选择 APP BIN 后通过 USB/UART 更新。网页只更新 APP；首次新版 BL 安装需 SWD 配套烧录。`?mock=1` 为演示设备，不能视为实板结果。

`20261004drift2` 在状态和测试页提供「重启设备」：发送普通系统重启 `0x15`，重新执行用户 BL 与启动零偏流程，按已保存配置启动并自动重连。UART 使用原端口和波特率；USB 重新枚举时找回唯一新增的同 VID/PID 端口。多个候选时停止并提示手动选择。测试进行中不能重启。

启动零偏历史的三轴值显示 5 位小数（显示位数不代表测量精度）。根据 `0x38` 本次启动初值及采集温度高亮「当前采用」记录，而非默认选最新记录或用不断调整的当前补偿匹配。不支持实际启动查询时不猜测；多条相同记录标注匹配项，并提示协议没有具体记录序号。

`20261005ins4` 测试页惯导位移估计显示 X/Y/Z（cm）与速度（cm/s），需要 APP `20261005i` 或更新版本及有效六面加速度校准。网页自动请求独立 200Hz 数据，无需修改原有输出协议、通道或频率。先平放静止2秒建立原点，X为初始前方的水平投影、Y向左、Z向上；初始前方接近竖直时拒绝建原点。

独立数据源使用六面校准后的加速度与原始六轴 VQF 四元数。固件在2kHz采样时逐点旋转加速度到地面系，再按输出周期完整平均，减少降采样混叠与转动时重力滞后。网页使用微秒设备时间、32位帧序号与会话token验证连续性，扣除固定重力9.80665m/s²后进行15ms低通和梯形积分。显示滤波、航向归零、磁航向与零角速保持不参与位置计算。单姿态初始化残差仅作质量检查，不再作为机体偏置扣除或拟合重力/比例系数。

默认自由运动关闭自动静止归零，保留匀速和缓慢平移的速度。板卡确实停止时可点击「确认静止，归零速度」，保持累计位置。可选「停靠模式」仍可能把匀速运动误判为静止，仅适用于有停靠约束的动作。丢帧、时间不连续、重启、姿态跳变、数据中断、融合配置变化和断线会停止积分并保留有效部分；重新建立原点才能继续。旧固件提示升级，未完成初始化时显示「—」，不显示假零位移。

纯惯导位置仍会累积漂移，六轴航向也会漂移；cm是显示单位而非精度保证。六面校准、静止初始化与手动零速约束不能替代外部位置/速度观测，不能从惯性信号可靠区分静止与匀速平移。

独立惯导协议沿用 AA55 帧与 CRC16-CCITT，小端数值。`CMD 0x40` 的7字节参数为 `enable:u8 + hz:u16 + token:u32`；hz允许50～500且整除2000。按接收端口返回 ACK，启用租约10秒，网页每4秒续期，同token续期保留帧序号；停用只匹配本token，不写Flash。复位默认关闭。

`MSG 0x41` 的60字节 v1载荷：偏移0 version:u8，1 flags:u8（bit0六面校准有效、bit1 VQF静止诊断），2 reserved:u16=0，4 token:u32，8 sample_seq:u32，12 sample_us:u32，16 period_us:u32，20 quaternion:4×float32，36 acc_ms2:3×float32，48 gyro_dps:3×float32。quaternion为周期末原始q6；acc是区间平均地面系加速度转换回周期末机体系的等效值，主机 `R(q)*acc` 恢复区间平均；gyro为周期平均补偿角速。sample_us为周期末微秒计时，时间与帧序号按uint32回绕。完整帧67字节。设置/校准/重启期间关闭流，传输丢包由帧序号检测。

`20261005mag1` 在测试页添加磁力计 Bx/By/Bz 实时曲线，单位 µT，沿用首页加速度波形的三轴颜色、最近10秒窗口、自动纵轴、放大、暂停及悬停数值。九轴和九轴相对角模式显示，六轴模式隐藏。数据是磁标定并映射到 IMU 机体轴后的磁场向量，与 VQF 的输入一致；不是地面坐标或原始寄存器值。

需要 APP `20261005k` 或更新的兼容版本。测试页可见且设备空闲时以20Hz发送只读 `CMD 0x42`（空载荷），读取最新50Hz磁场采样，不改变现有输出设置、不写Flash。离页、断线、设置/升级期间停止查询；相同采样序号不重复插入，过期数据清空，旧固件显示升级提示并停止重复查询。

`MSG 0x43` 的24字节 v1载荷：偏移0 version:u8=1，1 flags:u8（bit0有效且不超过200ms、bit1磁扰动），2实际融合mode:u8，3reserved:u8=0，4sample_n:u32，8sample_ms:u32，12Bx:f32，16By:f32，20Bz:f32。沿用AA55/CRC及小端格式，回复回显请求seq。磁扰动时保留真实曲线并标注扰动，传感器无有效采样时不显示假零值。

本地浏览器演示：`?mock=1&magdemo=1#/test`；`magdemo=6axis/relative/legacy/invalid/disturbed` 可验证不同状态。演示不代表实板测量。

`20261006led1` 设置页「设备」中新增 WS2812 指示灯开关：切换后立即生效并自动保存，读回确认后显示开启/关闭状态，无需点击启动配置的「保存」。关闭会停止呼吸、校准、磁扰动和故障灯色；除初始化或首次关闭时的一帧黑色外，不再重复发送灯带波形。旧配置默认开启。测试、校准、升级或保存过程中禁止切换。

配套 APP 为 `20261006a`；若也要在用户 BL 等待和启动零偏采集时保持熄灭，需要同时更新本次配套 BL。仅更新 APP 时，旧 BL 的蓝灯逻辑仍会运行，进入 APP 后按保存设置关闭。

WS2812 协议：只读 `CMD 0x44` 空载荷；`CMD 0x45` 的1字节参数为 enabled（0/1），成功先保存再应用，返回 ACK 和状态帧；`MSG 0x46` 的4字节载荷为 `[version=1, active_enabled, saved_enabled, reserved=0]`，回显请求seq。前端需 ACK 成功及 active/saved 都匹配才确认保存；失败回滚开关显示，超时提示读取核对。

持久化保留原 v8 68字节配置记录，兼容已安装旧 BL 的 CRC/启动参数解码。WS2812 状态存于同槽紧随其后的16字节扩展（magic `0x57534C45`、同记录sequence、enabled:u32、CRC32）。写入顺序：主记录前64字节、扩展、主记录CRC作为最后提交；中途失败保留另一槽的完整记录。缺失或损坏的扩展默认开启，不丢弃主配置。配套 APP/BL 都在灯初始化前读取该设置，避免关闭状态启动时闪一下蓝灯。

模拟验证：`?mock=1&wsdemo=1#/settings`；`wsdemo=legacy/fail` 用于旧固件及保存失败的演示，均不控制实板。

### 融合算法（20261007ekf1）

设置页可选 VQF 或 EKF（四元数误差状态扩展卡尔曼），支持六轴、九轴和九轴相对角。“保存并重启”先确认 ACK 和实际保存回读，再发送普通重启并自动重连原 USB/WebUSB/UART。重启后的读取显示当前与已保存算法。旧固件禁用选择并提示升级到 APP20261007a。默认保持 VQF；不自动认为 EKF 的零漂一定更小。

协议：0x50 空查询；0x51 一个字节 0=VQF / 1=EKF，保存后等待普通重启应用；0x52 四字节 [1,active,saved,active!=saved]。修改中或测试/校准/升级期间禁止切换；Flash 失败或回读缺失不自动重启。零漂报告记录算法，避免跨算法混合统计。

### 磁力计校准（20261006magcal1）
校准页新增本地三轴原始采集、软硬铁椭球拟合与独立数据验证。先采集600样本并覆盖24/32方向，拟合后再采集300新样本进行模长/磁倾角验收，通过后保存到板卡，断电保留。需APP20261006b或更高版本提供0x47/0x49/0x4B/0x4C接口；无需更新BL。安装轴向仍沿用固件映射，本轮只检查倾角一致性，不自动拟合安装轴。旧固件提示升级，未保存前不会改变板卡校准。

`20261011magfit1` 修复少量不一致样本导致整轮拟合卡在笼统留出误差提示的问题。初次留出验收失败时，用仅由拟合样本建立的模型一次识别模长误差超过10%的异常样本；采集、拟合和留出各自最多剔除5%，剩余仍需600个样本、24/32方向及原RMS/P95门限。原始样本完整保留，页面及导出记录显示剔除数量、比例和失败指标。独立新数据验证不剔除、不放宽门限，未验证仍禁止保存。本地203项测试、模拟浏览器保存流程及721个历史实测样本回放通过；当前网页尚未发布，历史数据回放不是本次实板验证。

### 磁干扰拒绝开关
设置页“磁干扰拒绝”配合 APP 20261006c：默认开启、立即生效并断电保存。关闭后持续使用磁力计校正航向，真实磁干扰可能导致航向偏移。六轴不使用磁场；该开关不代替磁力计校准。协议0x4D查询、0x4E单字节0/1设置，ACK+0x4F状态(version/active/saved/reserved，各1字节)。旧APP提示升级。

### VQF 调参页（20261011a）

`#/tuning` 提供 14 项 VQF 参数：tauAcc、tauMag、biasSigmaInit、biasSigmaRest、biasSigmaMotion、biasClip、biasForgettingTime、restFilterTau、restMinT、restThGyr、restThAcc、magCurrentTau、magNormTh、magDipTh。

页面读取板卡的已保存值、实际运行值和编译默认值；输入范围和零偏不确定度关系在前端与固件两端校验。保存需要成功 ACK 和三页回读核对，再自动重启并重连使构造参数生效。「恢复默认参数」单击直接恢复并持久化全部 14 项默认值；其他校准和设备设置保留。自定义 VQF 参数优先于档位和静置初始化参数，不改变 EKF 参数。

需要 APP 固件 `20261011a` 或更新版本。旧固件返回不支持时禁止写入，提示升级。协议新增 `0x58` 查询、`0x59` 保存（60 字节）、`0x5A` 恢复默认和 `0x5B` 三页回读（0=已保存、1=默认、2=实际；每页 60 字节）。Flash 保持 v8 主记录和既有扩展布局，新增扩展位于偏移 196，扩展先于主 CRC 提交。

### 陀螺仪比例因子校准（20261011b）

固件 `20261011b` 起，调参页支持 X／Y／Z 独立比例系数（0.95～1.05，默认 1）。
热机并完成静止零偏校准后，使用六轴模式，平放转航向选 Z 轴，默认实际圈数 10。
点击准备采集并保持静止 2 秒，点击开始转动并等待提示，固定转轴单向转满指定圈数回到物理起始标记，
点击结束转动再静置 2 秒。设备平均角速度流以 200 Hz 传输，按设备采样周期累计完整角度；
丢帧、采样时钟中断、设备漏采或饱和计数变化、转轴不稳、反转、前后零偏明显变化均拒绝结果。
系数计算为 `测量时比例系数 × 实际累计角度 / |测得累计角度|`，不会把最后的航向偏差直接当作累计角度。
自动采集保留采集当时的系数和未舍入角度；保存重启后重复计算同一结果不会再乘新系数。
网页 `20261012scale2` 起，“使用已有测量结果”默认测量时系数为 1，手动填写未补偿的完整累计角度：
实际 10 圈测得 ±3600°，计算结果均为 1；测得 ±3585°，结果约为 1.0041841，与当前设备系数无关。
若输入已经补偿的测量值，应填写其测量时比例系数；手动编辑自动采集角度时会恢复基准为 1。
保存须有同序号 ACK 和准确回读，随后自动重启并重连。重启后在融合前校正陀螺仪角速度，
VQF／EKF、六轴／九轴均生效。保存后反向复测；恢复系数为 1 可撤销补偿。
该功能不校正机械转轴误差、交叉轴耦合，也不能替代零偏或温漂校准。

协议：QUERY `0x5C`（空）；SET `0x5D`（v1、保留 3 字节、3 个 float，共 16B）；RESTORE `0x5E`（空）；
状态 `0x5F`（v1、重启标志、保留 2 字节、当前／已保存 XYZ、漏采／饱和计数，共 36B）。
设置日志保持 v8 基础布局，新扩展位于 268B，24B CRC 记录在主记录 CRC 前提交。
旧日志缺少扩展或扩展无效时系数为 1；启动邮箱及零偏历史保持标称灵敏度单位。

### 运动数据采集（20261012capture1 / APP 20261012b）

导航新增「采集」页。连接设备后选择 1 / 5 / 10 / 20 / 50 / 100 / 200 / 500 Hz，点击开始采集，移动板卡，停止后导出 CSV。默认 100 Hz；页面显示预计每分钟文件大小、已采集行数、时长和大小。三张曲线显示最近 15 秒的加速度、角速度和姿态，文件保留所选频率下的全部记录。停止或断开后保留已采集的数据；导出并清空后可开始下一轮。单文件上限 64 MiB，到达上限自动停止；刷新或关闭页面会丢失未导出的数据。

CSV 每行包含 `ax_g,ay_g,az_g,gx_dps,gy_dps,gz_dps,yaw_deg,pitch_deg,roll_deg` 九个通道，以及电脑接收时间 `received_at_utc`、板卡原始微秒时钟 `device_time_us`、从首样本起的板卡时间 `elapsed_s`、样本序号、丢帧数、时间偏差、状态标记和采集配置。分析时间间隔使用 `elapsed_s`；电脑 UTC 时间是收到该帧的时间，两者没有做绝对时钟同步。32 位板卡时钟的正常回绕会连续展开；设备时钟或序号重置会停止采集并保留此前数据。

加速度与现有 IMU 遥测一致，是按当前量程换算的机体系读数，单位 g，含重力，未额外套用六面校准矩阵。角速度单位 °/s，含已有温度和比例因子修正，未减融合算法的自适应零偏。姿态来自同一采样时刻的当前融合和显示滤波输出，沿用当前航向参考及 ±180° 定义；航向卡片的 0～360° 显示切换不改变 CSV。低频采集抽取对应时刻的样本，不做平均；快速运动应提高采集频率。

独立采集流不修改日常输出频率、字段或持久化参数。采集中阻止校准、参数保存、重启、升级及惯导积分等互斥操作。CSV 的 `missing_samples`、`timing_gap_us` 和状态标记用于识别记录质量，不插值补造数据。UART 带宽不足时可能丢帧，高频采集建议使用 USB。

APP `20261012c` 起，采集端口的普通显示遥测临时限制到最多 100 Hz，给独立采集流和命令回读留出带宽；停止或租约到期后恢复原输出。其他端口和持久化输出配置保持原值。该措施减少传输竞争，不会修复 CSV 中已经缺失的记录，也不改变板卡内部 2000 Hz 姿态积分。

协议：`CMD 0x60` 为 7 字节 `[enable:u8,hz:u16LE,token:u32LE]`，用于开始、续期和停止；`CMD 0x62` 查询状态。`MSG 0x63` 为 12 字节 `[version=1,active,reserved:u16=0,token:u32,hz:u16,max_hz:u16=500]`。`MSG 0x61` 为 56 字节 `[version=1,flags,reserved:u16=0,token:u32,sample_seq:u32,sample_us:u32,period_us:u32,9×float32]`，整帧 63 字节；数值顺序与 CSV 九通道一致。flags 的 bit0 表示六面标定有效、bit1 静止、bit2 陀螺仪接近量程、bit3 加速度计接近量程。每个端口独立持有 token，10 秒无续期自动停止；上位机每 4 秒续期。修改命令在采集中返回忙状态。
