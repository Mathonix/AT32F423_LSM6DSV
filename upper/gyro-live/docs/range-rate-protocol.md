# 陀螺仪量程与输出频率（设备配置v3 / Flash设置v6）

启动命令0x1E继续接受3/5字节格式，新增7字节：mode:u8、fast:u8、立即重启:u8、初始化时长:u16LE、量程dps:u16LE。量程允许125、250、500、1000、2000、4000。设置模式中保存，重启生效；旧格式保留已保存量程。

设备配置0x07 v3为28字节，在v2的22字节后追加当前量程:u16LE、保存量程:u16LE、保存输出频率:u16LE。capabilities新增bit5=支持量程、bit6=频率自动持久化；原字段不移动。上位机兼容v1的18字节、v2的22字节。

输出频率0x1D仍发送Hz:u16LE。新固件先保存Flash，成功后更新运行频率，回复ACK及设备配置；保存失败保持原频率。频率须为2000Hz融合率的整数约数：1、2、4、5、8、10、16、20、25、40、50、80、100、125、200、250、400、500、1000、2000。与CAN周期独立。

CAN保持原0x22协议和period_ms字段，每类频率=1000/period_ms。输入范围0.1～1000Hz，取整毫秒间隔，页面显示实际值。例如50Hz=20ms，60Hz取17ms，实际约58.824Hz。主动模式下各勾选报文类型分别发送；请求模式按请求回应，频率不限制请求应答。总发送量仍执行总线带宽80%约束。CAN原断电保存机制不变。

Flash v6记录44字节，在v5的CRC位置前添加量程和频率。旧v2/v3/v4/v5各自按原CRC位置校验，双槽先验证CRC再按序号选最新。旧记录默认±1000dps和APP_VOFA_OUTPUT_HZ，保留其他已有配置。首次保存迁移；中断写入可退回旧槽。

量程与灵敏度依据[ST官方LSM6DSV驱动](https://github.com/STMicroelectronics/lsm6dsv-pid)：CTRL6 FS_G编码0/1/2/3/4/0xC，灵敏度分别为0.004375/0.00875/0.0175/0.035/0.07/0.14 dps/LSB。驱动初始化写入并回读核验，原始角速度、启动零偏、融合输入及诊断输出统一换算。
