# 上位机交接：应用固件版本

当前板上的应用版本是 `20261002c`。规则是日期加一个小写字母：同一天的第一版是 `a`，当天再出一版就用下一个字母。不要另起 `v1.0.0` 这种编号。这版带列出启动零偏历史的 `0x33`，见 `docs/host-agent-bias-history-list.md`。

网页源码还没改，也不要部署。九轴应用已于 2026-10-02 用 4 MHz SWD 烧到板上，应用区 `0x08008000`–`0x0801F334`，校验 95028 字节，SHA256 `9b613764bfff58c6a87f34baece5b5e095b0674c16825da275167974e75a19b7`。备份是 `artifacts/web-host/board-before-host-upgrade-20261002-203532.bin`。引导区 Reset 仍是 `0x08003301`，配置和校准区保持烧录前的内容。USB 回读 `0x23` 得到 `20261002c`。已保存并正在使用的设置是 6 轴、滤波档 0、±1000 °/s、快速启动开、开机采集 2000 ms、输出 1000 Hz，与备份里最新记录（`0x0803D800`，序号 155）一致。网页升级用 `build/lsm6dsv_spi_test/release-9axis/lsm6dsv_spi_test.bin`。旧固件不认识 `0x23`，会回 ACK `status = 0x01`。这时「当前版本」继续显示 `--`。线上页面还不会发 `0x23`。

## 查询

空命令 `0x23`。成功时不回 ACK，只回消息 `0x32`，16 字节。载荷不是空时回 ACK `status = 0x02`，不回版本帧。

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | uint8 | format，固定 1 |
| 1 | uint8 | 版本文本长度，当前是 9 |
| 2 | char[14] | ASCII，以 0 结尾。当前是 `20261002c` |

用长度取出文本显示到升级页的「当前版本」。不要把 `0x09` 当成版本帧，`0x09` 仍是 48 字节运动零偏。

连上以后可以发一次 `0x23`。采集静置初始化期间也允许查。版本只表示这次编译的应用，不随滤波档、量程或静置初始化改变。
