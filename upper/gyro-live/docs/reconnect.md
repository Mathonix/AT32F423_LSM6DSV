# 配置重启后自动重连

触发入口：保存启动配置并勾选立即重启；或设备物理重启、拔插导致串口移除/致命读取错误。只要本页此前连接过该端口就尝试恢复，覆盖其他配置保存后的重启。保存失败不会主动断开并重连。

以本次已授权的 SerialPort 对象为唯一目标，保留实际打开波特率及解析选择。不调用 requestPort 弹出选择框，不按 VID/PID 选择第一台同型设备。网页无法直接获取系统 COM 名称，原端口对象绑定仍由浏览器和系统管理；刷新网页后的首次连接需要重新选择。

先取消读取，等待旧读循环结束，释放写锁并关闭端口，随后重开旧对象。端口暂不可用每700ms重试；打开成功后继续查询配置/系统状态，避免 MCU 初始化期间丢失首次查询。90秒后仍不可用则停止并提示检查设备。手动断开取消计时器和连接代次；打开操作稍后完成时也会立即关闭，不意外重新接管设备。

浏览器回归通过：UART重启但COM持续存在、USB移除后延迟回来、移除前ACK丢失、端口打开后设备尚未响应、保存失败、打开过程中取消、重试间隙取消、先保存后物理重启。每个恢复场景同时放置两台相同VID/PID的模拟设备，确认始终只打开原对象、选口窗口只出现一次。测试使用模拟串口，报告在仓库 `artifacts/web-host/reconnect-browser-20261001.json`；真实USB重新枚举仍需实板验证。

参考：[Chrome Web Serial 官方说明](https://developer.chrome.com/docs/capabilities/serial)。
