# LSM6DSV 陀螺仪代码问题清单

> 更新时间：2026-09-13
> 审查方式：只读静态代码审查  
> 审查范围：LSM6DSV SPI驱动、六轴采样、上电校准及VQF调用流程

## 总体结论

当前LSM6DSV的寄存器配置、六轴数据顺序、灵敏度换算和VQF输入单位基本正确。当前主要风险集中在SPI错误处理、无效样本处理、六轴同步、丢样检测及长期运行可靠性。

## 优先处理顺序

### P0：必须优先处理

1. 修复SPI底层超时判断，让传输函数能够返回失败。
2. 让寄存器读取、burst读取和`lsm6dsv_read_raw()`完整传播错误。
3. 等待或读取失败时禁止调用`vqf_update()`。
4. 校准阶段只统计成功且新鲜的样本。

### P1：可靠性改进

1. 明确六轴DRDY同步策略，避免只就绪一路时读取六轴。
2. 正式运行时考虑把SPI时钟降至约4.6875 MHz。
3. 初始化后回读并校验全部关键寄存器。
4. 增加连续通信错误后的SPI和IMU恢复机制。
5. 增加静止检测，防止运动状态下进行零偏校准。
6. 使用FIFO、DRDY计数或时间戳检测丢样。

### P2：代码质量改进

1. 改用8位SPI事务，或明确记录16位事务的额外读取行为。
2. 对复合功能寄存器使用read-modify-write。
3. 增加参数和空指针检查。
4. 清理无用常量、旧诊断接口及过时文档。

## 已确认正确的部分

- `CTRL6 = 0x03`：陀螺仪量程为±1000 dps。
- `CTRL8 = 0x01`：加速度计量程为±4 g。
- `HAODR_CFG = 0x01`，`CTRL1/CTRL2 = 0x1A`：HA01模式，目标ODR为2000 Hz。
- `CTRL3 = 0x44`：启用BDU和寄存器地址自动递增。
- `IF_CFG = 0x01`：禁用I²C/I3C，使用4线SPI。
- 陀螺仪灵敏度`0.035 dps/LSB`正确。
- 加速度计灵敏度`0.000122 g/LSB`正确。
- 从`OUTX_L_G`连续读取时，数据顺序为陀螺仪XYZ、加速度计XYZ。
- VQF陀螺仪输入使用rad/s，加速度计输入使用m/s²，单位正确。
