# 上位机交接：零角速保持阈值可改

这次固件增加了读写零角速保持阈值的命令。网页源码还没改，也不要部署。旧固件不认识这两个命令。

零角速阈值命令已包含在 2026-10-02 烧录的 9 轴应用里，SHA256 `48f50b5f2529316af81cd0a5061b07bb738444e52f0f71eb574e2e8788448e42`。不要改已保存的融合模式、滤波档和陀螺量程。

## 用户能改的量

只在第 3 档且融合模式为六轴时，这些数才会锁定发布航向。九轴选第 3 档仍不锁磁力计航向。改阈值不会切换档位。

角速度仍是温度补偿后的陀螺减去当前 VQF 零偏，单位 °/s，三轴合成模长。进入看低通后的 RMS，退出看未滤波模长。加速度偏差只参与进入，不参与退出。

| 字段 | 默认 | 允许范围 | 作用 |
| --- | --- | --- | --- |
| enter_dps | 0.30 | 0.05～2.00 | RMS 低于此值才累计进入 |
| exit_dps | 0.70 | 必须大于 enter，且 ≤ 5.00 | 未滤波模长高于此值才累计退出 |
| acc_dev_ms2 | 0.15 | 0.02～2.00 | 加速度模长相对重力的偏差，小于此值才允许进入 |
| enter_filter_ms | 10 | 0～200 | 进入用的速率平方低通，0 表示不低通 |
| enter_confirm_ms | 50 | 0～2000 | 进入确认 |
| exit_confirm_ms | 3 | 0～500 | 退出确认 |

没有保存过阈值的旧配置，读回来就是上表的默认值。保存阈值时，模式、档位、量程、输出速率和 CAN 配置会原样写回，不要在这条命令里改它们。

修改立即作用于当前运行的锁定判断，不用重启。`persist = 0` 只留在本次运行，断电后回到已保存值。`persist = 1` 写入 Flash。

## 协议

帧仍是 `AA 55`，CRC16-CCITT。小端。`0x26` / `0x0B` / `0x27` 的字节和 capabilities 都不变。设备配置帧的能力位也不变。

旧固件收到 `0x2E` 或 `0x2F` 会回 ACK，`status = 0x01`（未知命令）。这时隐藏阈值编辑区，不要把未知应答当成写入成功。

查询不需要设置模式。写入必须先 `0x17` 进入设置模式，和改滤波档一样。未进入设置模式时 `status = 0x03`。参数不合法时 `status = 0x02`。Flash 写入失败时 `status = 0x03`，运行中的阈值保持原值。

### 查询 `0x2E`

载荷长度 0。成功时回消息 `0x0F`，不回 ACK。长度不为 0 时回 ACK，`status = 0x02`。

### 写入 `0x2F`

载荷固定 20 字节：

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | float | enter_dps |
| 4 | float | exit_dps |
| 8 | float | acc_dev_ms2 |
| 12 | uint16 | enter_filter_ms |
| 14 | uint16 | enter_confirm_ms |
| 16 | uint16 | exit_confirm_ms |
| 18 | uint8 | persist，0 或 1 |
| 19 | uint8 | 必须是 0 |

成功或失败后都会先回 ACK（`detail = 0`），再回一帧 `0x0F`。用 `0x0F` 里的运行值和保存值确认结果，不要只看 ACK。

### 消息 `0x0F`

载荷固定 40 字节。`version` 必须是 1。长度不符就丢掉。

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | uint8 | version，现为 1 |
| 1 | uint8 | supported，1 表示本固件有零角速保持 |
| 2 | uint16 | 保留，0 |
| 4 | float | 当前 enter_dps |
| 8 | float | 当前 exit_dps |
| 12 | float | 当前 acc_dev_ms2 |
| 16 | uint16 | 当前 enter_filter_ms |
| 18 | uint16 | 当前 enter_confirm_ms |
| 20 | uint16 | 当前 exit_confirm_ms |
| 22 | float | 已保存 enter_dps |
| 26 | float | 已保存 exit_dps |
| 30 | float | 已保存 acc_dev_ms2 |
| 34 | uint16 | 已保存 enter_filter_ms |
| 36 | uint16 | 已保存 enter_confirm_ms |
| 38 | uint16 | 已保存 exit_confirm_ms |

`supported = 0` 时不要提供编辑。六个数不是有限数，或落在上表范围外，整帧按无法识别处理。

连接后和读取滤波档时一起发 `0x2E`。保存成功的判断：ACK `status = 0`，随后 `0x0F` 的当前值等于刚写入的值；若 persist 为 1，已保存值也要相等。超时保留界面上的修改，并提示未确认。

恢复编译默认值用另一条命令 `0x31`，见 `docs/host-agent-zaru-restore.md`。不要用 `0x2F` 在上位机再抄一份默认数。

## 界面

放在「姿态稳定性」里，第 3 档「零角速保持」下面。六个输入加上「重启后保留」。未进入设置模式时输入和保存按钮不可用，读取按钮在已连接时可用。

退出阈值必须大于进入阈值。不满足时不要发送，直接提示。

文案保持：静止时锁定航向，检测到运动后解除。不要写成必须等待 VQF 的 1.5 秒静止标志。现有各档静止门限提示先不要改。

第 3 档在六轴下才按这些阈值锁航向。九轴下保存的数仍可读可写，但不会锁磁力计航向。界面上写明这一点。
