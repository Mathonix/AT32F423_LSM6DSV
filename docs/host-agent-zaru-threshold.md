# 上位机交接：零角速保持改为角速度双门限

这次只改了固件里的锁定判据。上位机协议、帧格式、档位编号都没有变。不要改网页，除非下面的文案还写着「必须等 VQF 判定静止」或「静止约 1.5 秒后才锁航向」。

不要刷机，不要部署。当前板上的程序还是上一版：进入锁定仍要等 VQF 静止。这份说明对应仓库里的新源码，要等用户明确要求后再烧录。

## 用户能感觉到的变化

第 4 档仍只在六轴锁定发布航向。Roll、Pitch 继续更新。九轴选这一档不锁磁力计航向。

- 运动时 Yaw 正常更新。
- 停稳后大约 100~200 ms 进入锁定，不再等 VQF 的 1.5 s `restMinT`。
- 锁定期间对外 Yaw 保持不动，内部漂移被航向补偿吃掉。
- 明显转动后大约 3~10 ms 解除，航向连续，不跳回内部角。
- 大约 0.30~0.70 °/s 之间保持当前状态：没锁上的不会锁，已经锁上的不会解。比这更慢的转动允许被吃掉一部分。

## 判据

角速度是温度补偿后的陀螺减去 VQF 当前零偏，单位是 °/s，三轴合成模长。不使用原始陀螺模长，也不使用 30 Hz 陀螺低通后的残差来解锁。VQF 零偏接口本身是 rad/s，固件里已换成 °/s。

加速度门只用于进入：加速度模长相对 9.80665 m/s² 的偏差小于 0.15 m/s²。它用来挡碰撞、平移和明显振动，不参与解锁。

| 宏 | 值 | 作用 |
| --- | --- | --- |
| `APP_ZARU_ENTER_DPS` | 0.30 | 10 ms RMS 低于此值才累计进入 |
| `APP_ZARU_EXIT_DPS` | 0.70 | 未滤波模长高于此值才累计退出 |
| `APP_ZARU_ENTER_FILTER_MS` | 10 | 进入用的速率平方低通 |
| `APP_ZARU_ENTER_CONFIRM_MS` | 50 | 进入确认 |
| `APP_ZARU_EXIT_CONFIRM_MS` | 3 | 退出确认 |
| `APP_ZARU_ACC_DEV_MS2` | 0.15 | 进入用的加速度偏差 |

VQF 仍每拍更新，静止时继续估计零偏。锁定不改 VQF 输入，也不改内部四元数。

## 上位机不用改的部分

- 档位仍是 0 响应优先、1 均衡、2 静态稳定、3 零角速保持。
- `0x26` / `0x0B` 和 `0x27` 的字节布局不变。capabilities 仍是 4。旧固件的 3 仍要能解码。
- 没有新的诊断字段。现有遥测结构体没有加 ZARU 状态。
- 第 4 档回读的时间常数仍是均衡的 4.0 / 0.50 s。
- 设置模式、保存位、六轴/九轴切换方式都不变。

界面若已经是「零角速保持：静止时锁定航向，检测到运动后立即恢复更新」，可以保留。不要把副标题改成等待 VQF 静止。

## 板子现状

2026-10-02 经 USB 保存的配置仍是：六轴、量程 ±125、滤波运行和保存都是 3。先 `0x26` 读回，不要改档，不要把这次读回当成出厂默认。

烧录新固件之前，实机仍会在 VQF 报告静止后才锁航向。
