产品简介
DM-IMU-L1 是一款内置BMI088 三轴加速度计+三轴陀螺仪自带EKF 四元数姿态解算IMU
产品。主控频率高达200MHz，支持USB、RS485、CAN 协议输出，支持输出加速度、角速
度、欧拉角、四元数等数据，数据输出频率高达1kHz。传感器芯片底部采用孤岛结构设计，
提升IMU 抗震性能。传感器芯片周围带有加热电路，可实现恒温控制，有效减少陀螺仪温
漂，无全温标定。
主要特性
1.支持CAN、USB、RS485 协议输出。
2.支持100-1000 输出频率可调。
3.自带加热电路可实现恒温控制。
4.内部EKF 算法姿态解算。

uint16_t Get_CRC16(uint8_t *ptr, uint16_t len)
{
uint16_t crc = 0xFFFF;
for (size_t i = 0; i < len; ++i)
{
uint8_t index = (crc >> 8 ^ ptr[i]);
crc = ((crc << 1) ^ CRC16_table[index]);
}
return crc;
}
