# AT32F423 AHRS 使用指南

更新：2026-10-24。适用于当前 master APP **20261024c**；实际连接后，以设备回读版本和配置为准。本文不包含任何板卡私有校准或温度模型快照。较早本地交接文档中的“当前板上/最新发布”属于各自历史时点。

## 1. 当前功能与验收范围

硬件为 AT32F423 150 MHz、LSM6DSV IMU、IST8310 磁力计和 PA8 WS2812。可选择 VQF、EKF、ESKF，算法保存并重启后生效。

| 当前 ESKF 路径 | 配置 |
|---|---|
| 滤波状态 | 单套三维姿态误差 ESKF，六轴/九轴通过磁融合开关切换 |
| IMU采集 | DRDY → SPI1 RX/TX DMA → 64帧SPSC环缓 |
| 四元数预测 | 标称8 kHz |
| 协方差传播 | `APP_ESKF_COV_DIV=4`，标称2 kHz |
| 加速度输入/完整重力观测 | 2 kHz / 标称500 Hz，门控可拒绝观测 |
| 姿态生成 | 独立1 kHz；端口发送率还受配置及通信状态影响 |

“8 kHz ESKF”在当前 master 指四元数预测频率，不能替代每样本完整协方差传播或双套独立ESKF的验收。

E版60秒WinUSB窗口 CPU约76.10%，约48万次DMA传输成功，busy/错误/超时/溢出均0，窗口内无新增姿态超龄；该窗USB CRC和可观察seq8缺口均0。但另一个20秒窗口出现11处序号缺口，正式窗口前已有1次姿态超龄。因此总体为 **CONDITIONAL PASS**，不是全负载、长期稳定或绝对角度精度认证。详见 [实板报告](SPI_DMA_BOARD_TEST_20261023.md)。

## 2. 连接设备

1. 接开发板原生USB并保持供电；启动零偏采集期间固定板卡，不拉扯连接线。
2. 打开 [gyroa](https://gyroa.233688.xyz/)，选择串口或WebUSB连接。页面可能与本地源码版本不同，先查询设备版本、算法、量程、模式和输出配置。
3. USB CDC串口按2000000 baud打开；原生CDC没有UART发线的波特率带宽约束。WebUSB使用独立vendor接口；它与CDC是不同句柄，一路被占用不代表另一路一定不可用。
4. 同一接口被其他程序占用时，断开该程序或改用未占用接口。不要让多个程序同时发送设置、保存、重启或升级指令。
5. 调试器UART连接为 PA0/TX → 接收器RX、PA1/RX ← 接收器TX，并共地。调试器串口与原生USB的连续吞吐/丢包结果需分别验证。

CAN2 使用 PA2/RX、PA3/TX，经板上收发器接 CAN_H/CAN_L。应有正确的总线终端、共地及相同波特率，接收端须正常模式提供ACK。彩灯不表示CAN供电、ACK或总线健康；单看 CAN_TX/CAN_RX 活动也不能证明 SYS_5V>4.2V。

## 3. 选择算法与六轴/九轴

在设置页读取当前与已保存算法，选择 ESKF 后按页面提示保存并重启，再读回确认。需要六轴时选择六轴模式；需要磁航向时选择九轴或九轴相对航向，并检查磁力计校准和磁场状态。

- 六轴：Roll/Pitch有重力参考；Yaw没有绝对航向参考，仍可能漂移。
- 九轴：磁观测可约束Yaw，但局部磁铁、电流和硬铁变化会影响航向。请求九轴不代表磁参考已就绪；灯光也区分等待/回退与真正就绪。
- 相对航向、手动归零、显示滤波、零角速保持属于输出层，不能当作内部滤波器绝对精度。
- 单套状态的模式切换不等于后台同时运行六轴/九轴两套独立滤波器。

当前 master 还包含加速度均值、较紧门限及恢复策略，协方差传播分频也不同于历史Z分支。不同固件的CPU、收敛、USB和精度结论不能互相替代。

## 4. 静置检测、零偏跟踪和校准

启动窗口由保存的设置决定（支持0～60秒；默认2秒）。T=0使用历史快速启动，T>0尽量保持静止；不合格时可能回退到历史或无历史路径。用启动零偏来源查询区分实际采用的数据，不假定总是采用最近一条历史。

静置检测表示当前算法的门控结果；启用静置零偏跟踪后，符合条件时更新残余偏置。关闭跟踪通常保留已学补偿，不能将其理解为清除校准。ESKF当前rest tracker与旧VQF/EKF参数不完全等义。

静置灯语开关只改变呼吸速度提示，不改变检测或学习。当前ESKF启动/常态门控、EMA、回退历史及bias限幅详见 [配置](../inc/app/eskf8k_config.h) 和 [rest实现](../inc/fusion/reference_rest.hpp)。不要仅修改旧的未参与当前消费者路径的宏。

静置零偏采集需要固定板卡；六面加速度校准按上位机提示依次摆放各面；磁校准须按提示转动并远离磁干扰。六面过程的黄色闪烁次数对应当前第几面，具体方向以页面为准。保存后读取状态确认，避免把一次失败流程算作成功。

绕重力轴匀速慢转可能与偏置难以区分；静置标志或短时Yaw稳定不能证明慢转不会被误学习。

## 5. 输出与故障排查

- 设置输出协议、频率、字段后重新读取确认。1kHz内部生成不保证任何接口都无条件收到1000帧/秒。
- VOFA+使用匹配的JustFloat通道数。向现有输入发送ASCII `vofa`可临时切换输出，不写Flash；它不是AA55协议命令。
- 当前关闭了原1.5秒静置输出保持；若再出现卡值，分别检查内部姿态、输出滤波/ZARU、协议帧时间与主机接收，不能直接归因于陀螺采样停止。
- Pitch/Roll恢复速度涉及重力观测门控、增益和输出滤波；不要仅为更快显示盲目调小R或放宽动态观测。
- DMA错误、busy、超时或环缓溢出必须作为异常记录。CRC正常仍可能丢帧；8位seq也不能排除恰好整256帧的缺失。

当前只读诊断（AA55帧）包括：

| 请求 → 回复 | 用途 |
|---|---|
| `0x23 → 0x32` | APP版本 |
| `0x1F → 0x07` | 配置；source字节是回复接口，不是模式 |
| `0x50 → 0x52` | 当前/保存算法和待重启状态 |
| `0x37 → 0x38` | 实际启动零偏来源与状态 |
| `0x74 → 0x75` | 采集、预测、姿态计数 |
| `0x76 → 0x77` | 姿态年龄/间隔与累计超龄 |
| `0x78 → 0x79` | DWT分桶；索引15是DMA IRQ，须与DRDY桶一起评估 |
| `0x82 → 0x83` | DMA采集账本、busy/错误/超时/溢出及水位 |
| `0x6B → 0x6D` | 静置灯效开关状态 |

命令需通过现有协议编码器封装并计算CRC；不是直接发送文本“0x82”。`0x56`等设置指令可能保存Flash，不应作为只读查询使用。当前master没有Z的USB入队账本查询，不能据旧分支说明假定支持。

## 6. 构建、升级和数据保护

固件需要GNU Arm工具链与Make；Windows可用：

```powershell
mingw32-make -B DEBUG_BUILD=0 SIX_AXIS=0 all
```

`SIX_AXIS=0`为具备磁融合能力的通用构建；实际模式取决于保存配置。`SIX_AXIS=1`为强制六轴构建。默认产物目录见 [README](../README.md)。上位机在 `upper/gyroa` 执行 `npm ci`、`npm test`、`npm run build`；部署网页与推送固件源码是不同操作。

| 区域 | 地址范围 |
|---|---|
| Bootloader | `0x08000000`～`0x08007FFF` |
| APP | `0x08008000`～`0x0803BFFF` |
| 设置、校准、模型等保留数据 | `0x0803C000`～`0x0803FFFF` |

有配套BL的板卡优先使用网页/串口APP升级。先确认版本、接口身份、pending及未保存RAM数据；需要保留时先导出，再选准确BIN，核对SHA256，等待上传/整镜像CRC/重连验证。不得整片擦除，不用旧整片备份覆盖新校准或温度模型。APP更新不改变BL灯效；首次安装BL须单独按其指南处理。

当前master的温度学习和自动保存仍存在：新学习范围10～60°C，合格静止10秒后采集30秒；模型持久化有等待时间、磨损和冲突门控。另有独立启动零偏历史journal保存路径，不能把两者混作一个开关。保存可能使Flash执行停顿，**SPI DMA不等于Flash busy期间完整采集链运行于SRAM**，该并发场景未通过验收。具体状态先读取，不自动丢弃或强行持久化待存模型。

本轮E源码推送不自动创建Release、不上传私有校准/模型/原始抓包，也不自动部署网站。

## 7. WS2812灯语（指南末尾）

以下对应当前 `src/bsp/ws2812.c` 和 `src/app/main.c`。灯光总开关关闭时彩灯熄灭；呼吸周期是主循环正常服务时的标称值。板上固定电源灯、调试器灯不属于此表。

| 灯效 | 含义 / 建议 |
|---|---|
| APP初始化时蓝色常亮 | 启动阶段；随后应进入校准、普通呼吸或故障提示 |
| 蓝色每秒快闪两下 | 静置校准准备/采集；亮80ms、灭100ms、再亮80ms。配套BL等待/采集也采用此灯效，实际取决于已安装BL版本；升级通信中动画可能暂停 |
| 绿色慢呼吸，约3秒一周期 | 普通六轴状态，或磁参考尚未就绪；不能仅凭绿色判断用户配置一定为六轴 |
| 青色慢呼吸，约3秒一周期 | 磁参考已就绪的九轴状态；不是绝对磁航向正确性的保证 |
| 绿/青色呼吸加快至约0.75秒一周期 | 静置指示器开启且算法判为非静置，**速度为慢呼吸的4倍**；指示器关闭时均保持约3秒，不影响静置算法 |
| 绿色呼吸叠加青色快闪，约8Hz | 请求九轴、磁样本到达，但未建立磁参考且场强在默认20～80µT锁定窗口之外，进入六轴回退提示；排查局部磁干扰/校准。该提示优先于普通运行的红/黄警告叠加 |
| 已就绪九轴的青色为主、周期性切绿色 | 磁观测被拒绝/受扰：默认每750ms正常色后显示250ms绿色；不是上面8Hz未锁参考回退 |
| 每约2秒叠加两次短红闪 | 启动校准未能采用新鲜结果且无可用历史（`bias_no_history`）；检查启动时是否移动。仅回退到可用历史不必然触发此红闪 |
| 每约1秒短黄闪一次（约120ms） | 有设置待重启生效，或零偏历史写入错误；用状态查询区分，不仅凭颜色判断原因 |
| 绿色/青色常亮，不呼吸 | 设置模式；颜色随当前实际六/九轴指示，普通运行警告暂停 |
| 黄色成组闪1～6下后停顿 | 六面加速度校准当前面提示，按上位机要求摆放；每组约1.6秒 |
| 六面校准中每秒短红闪（约180ms） | 六面加速度校准失败；查看页面原因，再决定重试 |
| 红色常亮 | IMU/融合初始化失败等 `ws2812_show_error(1)` 路径；检查传感器、供电和通讯，不代表“正在测量角速度很大” |
| 橙色常亮 | 磁力计初始化异常（请求磁融合时）；六轴模式下磁力计缺失不应被直接当作永久故障 |
| 灯色异常，例如蓝显示粉、绿显示橙 | 不是新增状态码。先查供电、共地、信号电平/波形和灯珠；不要只据颜色推断滤波状态 |

灯效优先级：六面校准/失败 → 一次性静置校准 → 设置模式 → 普通运行；普通运行内先处理8Hz磁场回退，再按磁拒绝提示、红色启动警告、黄色设置/历史警告组合显示。只有短测代码明确接管灯光时，蓝/绿/红也可能代表人工动作提示，应以该轮测试说明为准。

## 8. 性能指标（单板实测摘要）

以下为单台工程样机在静置、常温实验室条件下的实测值，固件 20261024c、六轴 ESKF（`rest_tau_s=3.0`）、陀螺 4000 dps / 加计 ±4 g、USB CDC 2 Mbaud。这是**实测记录摘要，不是器件规格书**：未覆盖温度范围、多台一致性与动态工况，引用时请连同口径一起引用。本节即当前可对外引用的性能口径；更细的采样条件、被推翻的旧结论与复现命令不在本说明书范围内。

| 指标 | 实测值 | 口径 |
|---|---|---|
| 陀螺噪声密度 | gz 3.03 / gy 4.71 / gx 5.24 mdps/√Hz | 器件级；500 Hz、60 s、预滤波关闭、静置 |
| 陀螺角随机游走 ARW | gz 0.119 / gy 0.200 / gx 0.222 °/√h | 器件级；四次独立采集落在 ±6% 内 |
| 加计噪声 σ @500 Hz | 1.08 / 1.05 / 1.26 mg | 器件级；原始采样流，未经标定链路 |
| 启动倾角重复性 | roll sd 0.0098°，10 次全跨 0.0323° | 系统级；真断电，n=10，轮内 sd 仅 0.001–0.002° |
| 六轴 yaw 漂移 | +0.0030 °/h，3 h 净 +7.9 mdeg | 六轴、无绝对参考；去趋势 rms 2.67 mdeg |
| 端到端姿态延迟 | p50 1.999 ms，p99 2.003 ms @500 Hz | 系统级；抖动 std 0.005 ms |
| 采样丢失 | ESKF 0；VQF 0.96%（100 Hz 流）/ 4.0%（500 Hz 流） | 与算法和负载相关，不是链路丢包 |
| 加计 Z 两面中点残差 | 校正后 −5.47 mg；反推原始中点 −4.79 mg | 当前 Flash 系数与该次测量不符；重力项抵消以正反姿态互为反向为前提，Z 轴偏置不能直接折算为固定倾角误差 |

以下各项**尚未取得可引用的结论**，不要作为验收或选型依据：

| 项 | 状态 |
|---|---|
| 陀螺零偏不稳定性 | 仅得带上界的记录（含一次温度瞬态），Allan 平稳性前提不成立 |
| 加计轴间失准、绝对倾角误差 | 未测；手工六面倾斜 2.1–5.9°，数据被姿态误差支配，需夹具 |
| 温度特性 | 未测，是当前最大缺口 |
| 量程线性度、陀螺高速段比例 | 未测，需转台 |
| 动态绝对精度、带宽/频响、振动下性能 | 未测，需外部姿态基准与振动台 |
| 磁航向精度 | 未真正验证；现场磁场受扰，九轴未稳定工作 |
| 多台一致性、功耗、CAN 周期抖动 | 未测 |

跟踪全开时的滤波器闭环零偏残余（gz 约 0.0286 °/h）反映的是软件抑制能力，与器件零偏不稳定性相差约两个数量级，**不能当作器件指标**。同理，相对航向、手动归零、零角速保持等输出层功能也不代表内部滤波器的绝对精度。
